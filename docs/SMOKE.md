# 冒烟测试与验收矩阵

> 目标：每次发版前用一条命令覆盖核心链路；人工项按清单逐条勾。
> 命令：`pnpm smoke`（约 20–30 秒）
> 依赖：Chrome for Testing / Chromium（支持 `--load-extension`），默认路径见 `scripts/smoke.sh`，可用 `CHROME_BIN` 覆盖。

## 自动化覆盖（28 项）

## 人工清单（发版前）

1. 在真实站点（GitHub README / 新闻站 / 深色站点）各翻译一次，检查排版与配色。
2. 选中文本 → 浮标 → 气泡：换语言、复制、Esc、点击外部。
3. `Alt+A` 翻译中取消；再 `Alt+A` 还原。
4. 输入框：双击空格、`Alt+D`、`Ctrl+Z`。
5. 设置页：向导 3 步走完；测试连接；保存后重新打开确认持久化。
6. 断网后翻译：应提示网络不可用；恢复后可重试。
7. 打包产物安装一次（`.output/chrome-mv3`），确认图标/权限/弹窗正常。

## 已知限制

- 划词气泡在 closed Shadow DOM 内，自动化无法直接断言，只能人工验证。
- `commands` 快捷键由浏览器层处理，CDP 无法可靠触发，需人工。
- 缓存/用量是扩展本地存储，测试 profile 会被清理，数值每次从 0 开始。
