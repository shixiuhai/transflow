# TransFlow UX 审计与 v1.6.0 优化计划

> 状态：已实施（2026-11-26）
> 范围：设置页、扩展弹窗、单词本管理页、复习页、划词气泡
> 验证：34/34 冒烟、46 单测、360/390/454/1100 多轮截图

---

## 1. 当前实现审计

| 界面 | 现状 | 问题 |
|---|---|---|
| 设置页 | 单页长滚动，卡片依次排列；顶部有快捷栏 | 信息层级弱，找「单词本 / 用量 / 版本」要滚很久；单词本管理在设置里重复一整套列表 |
| 扩展弹窗 | 品牌 + 诊断框 + 语言 + 输入 + 结果 + tabs | 诊断框长期占据首屏；正常状态也显示调试信息；结果为空时仍展示一排禁用按钮；设置入口重复 |
| 单词本管理页 | 统计 + 搜索/筛选 + 列表 + 编辑/批量/导入导出 | 已较完整；空状态与移动端可继续打磨 |
| 复习页 | 深色专注模式，翻面 + 四档评分 | 缺少快捷键提示/撤销；移动端头部信息可再精简 |
| 划词气泡 | 四种样式（暖纸/自动/毛玻璃/高对比） | 按钮较多；缺少「固定/更多」等进阶动作（暂不做） |

结论：核心功能完整，主要问题是**信息架构**和**首屏噪音**，不是缺功能。

## 2. 业界参考

| 产品/模式 | 可借鉴点 | 应用到 TransFlow |
|---|---|---|
| [Immersive Translate Popup](https://deepwiki.com/immersive-translate/immersive-translate/4-user-interface#1) | 弹窗只放高频动作：开关、服务、当前页状态、设置入口 | 弹窗去掉常驻诊断，保留翻译/整页/词库/复习/设置 |
| [SaaS 设置页清单](https://www.saasui.design/settings-page-ui-design) | 复杂设置用 sidebar/tabs 分组；相关项放一起；即时反馈 | 设置页改成 5 个 section tab；同类卡片归组 |
| [SaaS navigation](https://raw.githubusercontent.com/oborchers/fractional-cto/refs/heads/main/saas-design-principles/skills/saas-navigation/SKILL.md) | 左侧/顶部主导航 + 上下文工具；不要重复入口 | 顶部快捷栏 + section nav；单词本只保留摘要，管理集中到独立页 |
| [Readwise Active Recall](https://blog.readwise.io/remember-more-of-what-you-read-with-readwise/) | 到期数量、每日回顾、低摩擦进入复习 | 快捷栏显示到期数；管理页统计待复习；一键开始 |
| Anki / Quizlet | 单卡聚焦、翻面、四档评分、键盘操作 | 复习页保留 Space/1-4，补快捷键提示 |
| Raycast / Linear | 命令式入口、紧凑状态、渐进披露 | 诊断信息只在异常时出现；空状态只留一句提示 |

设计原则：

1. **首屏只放高频动作**，调试/低频设置后置。
2. **一个功能只有一个主管理面**，设置页放摘要和入口。
3. **分组导航**优先于长滚动；同类设置放在同一 section。
4. **状态可见**：连接状态、到期数、上次同步、错误。
5. **键盘优先**：翻译 `⌘/Ctrl+Enter`；复习 `Space`/`1-4`/`Esc`。
6. **响应式**：360px 弹窗、390px 手机宽度、454px 窄设置页不横向溢出。

## 3. v1.6.0 实施清单

### 3.1 设置页

- [x] 顶部快捷栏：复习（到期数）、单词本管理（总数）、同步。
- [x] 新增 5 个 section tab：翻译渠道 / 阅读与划词 / 单词本 / 用量 / 关于。
- [x] 通过 `data-section` 只显示当前分组，避免长滚动。
- [x] 渠道卡改为 `auto-fit minmax(155px)`，454px 下 2 列，不再挤成 3 列。
- [x] 单词本 tab 精简为摘要：条数/待复习、UUID、同步频率、复习/管理/同步按钮、上次同步。
- [x] 恢复 UUID、导入导出、批量删除、删除云端统一收口到管理页。

### 3.2 扩展弹窗

- [x] 正常连接时不再显示诊断框；顶部状态显示「渠道 · 已连接」。
- [x] 仅在版本不一致 / 未注入 / 仅浮标时显示警告与「测试划词」。
- [x] 扩展页面/`chrome://` 不再误报「未注入」，显示「扩展页面」。
- [x] 空结果改为单行「译文会显示在这里」，不再展示一排禁用按钮。
- [x] 输入框增加清空按钮。
- [x] 底部 tabs：翻译 / 整页 / 词库（数量）/ 复习（到期数）/ 设置。

### 3.3 单词本管理

- [x] 统计：全部 / 待复习 / 新词 / 已掌握。
- [x] 搜索、筛选、排序、全选、批量删除。
- [x] 编辑原文/译文/上下文/笔记/标签；手动添加。
- [x] 导入 JSON、导出 JSON/CSV。
- [x] 同步面板：复制 UUID、恢复 UUID、立即同步、删除云端。
- [x] 390px 下统计 2×2、工具栏换行、列表不横向溢出。

### 3.4 复习页

- [x] 单卡聚焦、翻面、四档评分。
- [x] 键盘：Space 翻面、1-4 评分、Esc 返回设置。
- [x] 复习进度（mastery / reviewCount / nextReviewAt / intervalDays）随单词本同步。
- [x] 移动端 390px 可用。

### 3.5 划词气泡

- [x] 4 种样式：暖纸（默认）/ 自动 / 毛玻璃 / 高对比。
- [x] 字号、圆角、阴影、箭头跟随样式；暗色页面自动适配。
- [x] 按钮顺序：＋单词本 / 朗读原文 / 朗读译文 / 复制 / 关闭。
