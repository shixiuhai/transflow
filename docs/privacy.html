译流 TransFlow · 隐私政策

最后更新：2026-11-25 · 适用于浏览器扩展“译流 TransFlow”

我们不收集什么

扩展没有账号系统、没有自建服务器、没有遥测或分析 SDK。我们不会收集你的浏览历史、剪贴板、账号密码或设备标识。

会发送哪些数据

当你触发翻译时，当前需要翻译的文本会发送到你在设置中选择的第三方翻译渠道（例如火山引擎、百度翻译、OpenAI 兼容接口）。发送目的是完成翻译，数据保留与使用规则由对应渠道的隐私政策决定。

密钥与本地数据

API 密钥保存在浏览器本地存储 chrome.storage.local，不会上传到我们或任何第三方；译文缓存保存在浏览器本地（IndexedDB/扩展存储），可在设置中清空。

权限用途

  • storage：保存密钥、语言偏好、术语表与缓存。
  • activeTab / scripting：在用户主动触发时向当前页面注入翻译界面。
  • contextMenus：提供右键翻译入口。
  • <all_urls>：读取当前网页的可见文本以进行翻译；不会记录或上传浏览行为。

单词本同步（可选）

使用单词本同步时，扩展会生成一个随机 UUID，并将你主动加入单词本的词条与译文上传到作者自建的同步服务器 https://transflow.yizhiweb.top，仅用于跨设备恢复，不是翻译代理。该服务是个人简单实现，不保证稳定性、可用性、永久存储或数据不丢失；重要词库请定期导出 JSON 备份。服务端按 UUID 保存一个 JSON 文件，不收集账号、浏览历史或遥测。UUID 是唯一凭证，请勿公开；可随时清空本地词库或调用删除接口移除服务端数据。

你的控制权

你可以随时在设置中删除密钥、清空缓存，或直接卸载扩展；卸载后本地数据随之删除。

联系我们

问题与隐私相关请求请通过项目仓库的 Issues 联系。

English summary

TransFlow does not collect telemetry or browsing history. Text you choose to translate is sent only to the translation provider you configure. API keys and caches stay in your browser's local storage and can be cleared at any time. Contact us via the project's GitHub Issues.
